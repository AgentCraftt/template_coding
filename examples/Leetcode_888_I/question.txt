You are given two strings `s` and `t` of lengths `m` and `n` respectively. You need to determine if `t` is an **anagram** of `s` after removing exactly `k` characters from `t`. Return `true` _if you can transform_ `t` _into an anagram of_ `s` _by removing exactly_ `k` _characters, otherwise return_ `false`.  **Note**: An anagram of a string is another string that contains the same characters, only the order of characters can be different.
