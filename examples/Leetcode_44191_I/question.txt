You are given a list of tasks represented as integer values, where each task needs to run at a specific interval. Each task takes one unit of time to complete, but there must be at least `n` units of time interval between two instances of the same task. You need to determine the **minimum time** required to complete all the tasks in the list. Implement a function that takes a list `tasks` of characters representing the tasks and an integer `n`, and returns the minimum time required to complete all tasks considering the cooldown period.
